# gstack

Use the `/browse` skill from gstack for all web browsing. Never use `mcp__claude-in-chrome__*` tools.

Available gstack skills:

- `/office-hours` — structured async Q&A with stakeholders
- `/plan-ceo-review` — prepare a CEO-level plan review
- `/plan-eng-review` — prepare an engineering plan review
- `/plan-design-review` — prepare a design plan review
- `/design-consultation` — consult on design decisions
- `/design-shotgun` — rapid multi-option design generation
- `/design-html` — generate HTML/CSS designs
- `/review` — code review
- `/ship` — ship a feature end-to-end
- `/land-and-deploy` — land and deploy changes
- `/canary` — canary deploy and monitor
- `/benchmark` — run benchmarks
- `/browse` — headless browser for web browsing, QA, and screenshots
- `/connect-chrome` — connect to a Chrome instance
- `/qa` — full QA pass
- `/qa-only` — QA without implementation
- `/design-review` — review a design
- `/setup-browser-cookies` — configure browser cookies
- `/setup-deploy` — set up deployment
- `/setup-gbrain` — set up gbrain integration
- `/retro` — run a retrospective
- `/investigate` — investigate a bug or issue
- `/document-release` — document a release
- `/document-generate` — generate documentation
- `/codex` — codex-powered tasks
- `/cso` — chief of staff operations
- `/autoplan` — auto-generate a plan
- `/plan-devex-review` — developer experience plan review
- `/devex-review` — developer experience review
- `/careful` — careful/slow mode for high-risk changes
- `/freeze` — freeze a branch or deployment
- `/guard` — guard mode for automated PR checks
- `/unfreeze` — unfreeze a branch or deployment
- `/gstack-upgrade` — upgrade gstack
- `/learn` — learn from a codebase or document
